# BharatSpectral Documentation (`docs/`)

This directory contains formal capstone proposals, defense grounding notes, roadmap milestones, and interactive HTML workflow reports.

---

## 📑 File Directory & Purpose

### 1. Research & Master Plans
* [`project_synopsis.md`](project_synopsis.md) — **Master Capstone Synopsis & Proposal:** Formal problem statement, national relevance (IndiaAI & ISRO Bhoonidhi), mathematical formalization of the 7 innovations, and expected outcomes.
* [`midterm_defense_grounding_and_gis_analysis.md`](midterm_defense_grounding_and_gis_analysis.md) — **Defense Grounding & GIS vs AI Analysis:** Detailed mathematical comparison between classical GIS spectroscopic tools (SAM, Linear Spectral Unmixing) and BharatSpectral-MAE, including baseline proofs on Indian agroecosystems.
* [`MASTER_PLAN.md`](MASTER_PLAN.md) — **Master Execution Roadmap:** Step-by-step milestone tracker spanning Phase 0 (Data Pipeline) through Phase 5 (Defense & DPI Deployment).

### 2. Interactive Handbooks & Visual Pinboards
* [`workflow-handbook.html`](workflow-handbook.html) — Standalone interactive workflow handbook for development protocols.
* [`references_pinboard.html`](references_pinboard.html) — Interactive visual pinboard summarizing key literature, sensor specs, and spectral library references.

### 3. Phase-Specific Deep Dive HTML Reports
* [`phase1.html`](phase1.html) — **Phase 1:** Problem space, data acquisition (AVIRIS-NG / HysIS / EMIT), and pretraining architecture.
* [`phase2.html`](phase2.html) — **Phase 2:** Downstream task fine-tuning (crop classification, nitrogen estimation, sub-pixel unmixing).
* [`phase3.html`](phase3.html) — **Phase 3:** WebGIS product pillar, Cloudflare Workers ONNX inference engine, and tile serving.
* [`phase4&5.html`](phase4&5.html) — **Phases 4 & 5:** Ground truth validation, cross-season generalization, deployment, and final defense preparation.
