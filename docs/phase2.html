🌟 1. The Big Picture: Turning Invisible Light into Tangible Impact
What happens now that our data is downloaded and cleaned? Where are we going?

In Phase 1, we scoped the data landscape and created a clean pipeline to download, calibrate, and strip out atmospheric water vapor noise from over 200 continuous narrow spectral bands.

Now in Phase 2, we unlock what the human eye and standard RGB satellites cannot see. Standard satellite pixels are like looking at a crowded room through frosted glass; hyperspectral imaging lets us hear every individual voice in the room. Phase 2 creates our first generation of AI models and spectral unmixing algorithms that translate raw wavelengths into real answers for Indian agriculture and ecology.

🌾 The Three Real-World Questions Phase 2 Answers:
1. Precision Agriculture: Is this wheat or mustard crop suffering from early-stage Nitrogen/Zinc deficiency or moisture stress 7 to 14 days before leaves visibly turn yellow?
2. Stubble Burning Prevention: In the post-paddy harvest of Punjab and Haryana, which fields contain dangerously dry, combustible residue ready to be ignited versus damp plowed soil?
3. The "Mixed Pixel" Mystery: A single satellite pixel covers a 30m × 30m ground patch. Is it 60% paddy, 25% bare soil, and 15% standing water? Spectral unmixing calculates the exact percentage breakdown of every material inside that pixel.

📓 3. The 4-Stage Modular Jupyter Notebook Suite
Organized, reproducible notebooks designed to turn you into a power user of HPC and AI workflows.
01
01_airawat_ingestion_and_bbr.ipynb
CPU Allocation (7GB RAM)

The gateway notebook. Loads standardized Zarr datacubes, validates band metadata, applies out-of-core chunking with Dask to prevent memory crashes, and confirms atmospheric water-absorption bands (1350–1420nm and 1800–1950nm) have been removed.

Primary Role
Memory-Safe Chunking & Validation
Memory Budget
< 2.5 GB RAM (Dask Windows)
Key Output
Streamable Zarr Arrays on Disk
02
02_spectral_profiling_and_unmixing.ipynb
CPU / GPU Interactive

Acts as the Spectral Detective. Extracts pure reference spectra (endmembers) using Vertex Component Analysis (VCA), compares observed pixels against the USGS Spectral Library v7 using Spectral Angle Mapper (SAM), and trains a lightweight autoencoder to decompose mixed pixels into fractional abundance heatmaps.

Algorithms
SAM, SID, VCA, Blind Autoencoder
Spectral Prior
USGS Spectral Library v7
Key Output
Fractional Abundance Rasters (0–100%)
03
03_baseline_spatial_spectral_models.ipynb
NVIDIA DGX A100 GPU

The deep learning proving ground. Implements, trains, and tunes three foundational neural architectures in PyTorch: a 1D Spectral CNN (fast point classifier), a 2D Spatial CNN (patch classifier), and a state-of-the-art 3D HybridSN (joint spatial-spectral CNN).

Architectures
1D-CNN, 2D-CNN, 3D-HybridSN
Compute Target
A100 GPU (PyTorch + CUDA)
Key Output
Trained PyTorch Model Checkpoints (.pt)
04
04_evaluation_and_ablation_metrics.ipynb
CPU / GPU Analysis

The executive scoreboard. Evaluates model performance across Overall Accuracy (OA), Cohen’s Kappa (κ), and per-class F1-scores. Generates beautiful confusion matrices, class prediction overlays, and visualizes TensorBoard training curves.

Metrics Computed
OA, Kappa (κ), Per-Class F1, RMSE
Visualizations
Confusion Matrices, Abundance Maps
Key Output
Benchmark Leaderboard & Plots
🧠 4. The Baseline Deep Learning Models Explained
Understanding the three architectural approaches we test against each other in Phase 2.
Model Architecture How It Sees The Data Key Strengths Primary Limitation AIRAWAT A100 Training Time
1D-Spectral CNN Examines 1 pixel at a time across its 200+ continuous spectral wavelengths (pure spectral profile). Extremely lightweight, lightning-fast inference, zero spatial context dependency. Ignores neighborhood context; can misclassify single noisy pixels. < 3 Minutes
2D-Spatial CNN Examines spatial patches (e.g. 15×15 pixels) across a reduced set of spectral bands or PCA components. Captures farm field boundaries, geometric textures, and crop row patterns. Discards subtle continuous narrow-band absorption signatures. ~ 6 Minutes
3D-Spatial-Spectral (HybridSN) Examines a 3D cube (15×15 spatial window × 200 spectral bands) with 3D kernels, followed by 2D refinement. Unrivaled accuracy on complex agricultural sub-classes (e.g. differentiating mustard from canola). Higher parameter count; requires GPU acceleration. ~ 15 Minutes
⚡ 5. Harnessing India's AIRAWAT Supercomputer
How we connect to high-performance A100 nodes and master interactive Jupyter development.
🖥️
Interactive Jupyter Tunneling
Instead of running heavy models on limited laptop hardware, we launch a headless JupyterLab instance directly on an AIRAWAT A100 node and securely tunnel the interface to our local browser via SSH port-forwarding:
ssh -L 8888:node042:8888 user@airawat.cdac.in
Zero Local GPU Needed Full Interactive Code Execution
📊
Self-Contained Experiment Tracking
Supercomputing compute nodes operate in secure, isolated environments without public internet access. We use local TensorBoard and structured JSON logging to monitor loss curves, learning rates, and gradient stability in real time without external cloud dependencies.
TensorBoard Offline Instant Loss Visualizations
🛡️
Strict Memory Guardrails
Hyperspectral cubes are massive. Our notebooks strictly adhere to our < 2.5 GB RAM guardrail by streaming sliding-window patches directly from Zarr arrays into PyTorch CUDA memory using pinned memory buffers, preventing Out-Of-Memory (OOM) crashes.
Dask Chunking CUDA Pinned Memory
The Capstone Horizon
A Glimpse of the Final Vision: Hyperspectral Intelligence in Action

By the time we complete all five phases, our project will not merely be a research paper or a set of notebooks. It will be a living, breathing Edge-to-Cloud Hyperspectral Intelligence System that empowers Indian citizens.

🌾 The Kisan Citizen Web Portal
A lightning-fast, zero-egress WebGIS map powered by Cloudflare Workers and R2. A farmer or district officer can zoom into any village in India, click their field, and view a continuous soil fertility score, nitrogen health curve, and irrigation moisture index.
🔥 The Stubble Burn Alert System
An automated regional dashboard that flags agricultural plots with critically dry residue 48 hours before burning season peaks, helping state agricultural departments deploy tractor balers proactively.
📟 The Google Coral Offline Edge Scanner
A handheld or drone-mounted scanner running our strictly quantized INT8 model on a Google Coral TPU. It provides instant 15ms crop health diagnosis in rural fields with zero internet connection required.
